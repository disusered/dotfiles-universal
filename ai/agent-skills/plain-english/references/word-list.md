# Google Word List — the entries that bite

A curated subset of https://developers.google.com/style/word-list, limited to the entries
that actually catch generated prose. Every quotation below was taken from that page. For any
word not listed here, fetch the live page rather than guessing — it holds roughly 300 entries
and it changes.

## Filler to delete

| Word | Guidance |
| --- | --- |
| just | "Avoid. Usually, just is a filler word that you can delete without affecting your meaning." |
| easy, easily | "What might be easy for you might not be easy for others. Try eliminating this word from the sentence because usually the same meaning can be conveyed without it." |
| please | "Don't use please in the normal course of explaining how to use a product, even if you're explaining a difficult task. Don't use the phrase please note." |
| currently | "Avoid because this word is implied." |

## Substitutions

| Instead of | Use | Guidance |
| --- | --- | --- |
| leverage | use, build on, take advantage of | "Avoid using if you mean use. If possible, use a more precise term." |
| allows you to | lets you | "Don't use. Instead, use lets you." |
| in order to | to | "Avoid in order to; instead, use to. Use in order to when needed to clarify meaning or to make something easier to read." |
| execute | run | "When the meaning is the same, use the simpler word run instead." |
| desire | want, need | "Don't use. Instead, use a word like want or need." |
| e.g. | for example, such as | "Don't use. Instead, use phrases like for example or such as." |
| i.e. | that is | "Don't use. Instead, use phrases like that is." |
| as (causal) | because | "If you mean because, then use because instead of as." |
| once (temporal) | after | "If you mean after, then use after instead of once." |
| hit | click, press, type | "Don't use as a synonym for click, press, or type." |
| kill | stop, exit, cancel | "Avoid when possible." |
| check (a box) | select | "Don't use to refer to marking a checkbox. Instead, use select." |
| performant | a specific measure | "Avoid where possible. Instead, use a more precise term." |
| native (of software) | built-in | "Avoid using native to refer to people. When referring to software products, try to use a more precise term — for example, use built-in to describe a feature that's part of a product." |
| and/or | or, and, or both | "Don't use unless space is limited, such as in a table." |
| above / below (versions) | later / earlier | "Don't use for a range of version numbers." |
| back-end, back end | backend | "Not back-end or back end." |

## Modal verbs — pick deliberately

| Word | Guidance |
| --- | --- |
| must | "Use to describe a required action or state." |
| might | "Use to convey possibility or an uncertain outcome." |
| may | "In general, reserve for official policy or legal considerations." |

## Jargon with plain replacements

From https://developers.google.com/style/jargon:

| Instead of | Use |
| --- | --- |
| blast radius | affected area, spatial impact |
| ingest | import, load |
| off-the-shelf | ready-made, pre-built |
| hold a post-mortem | review what processes worked or didn't work |

Four options for any jargon term: write around it, replace it with something more specific,
define it on first mention, or link to a trusted definition.

## Not in Google's list

The guide predates LLM prose and says nothing about `robust`, `seamless`, `comprehensive`,
`delve`, `powerful`, or `cutting-edge`. Those live in
[ai-tells.md](ai-tells.md).
