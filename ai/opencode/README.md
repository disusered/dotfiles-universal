# OpenCode (deprecated)

Codex and Claude Code are the maintained development harnesses. Use
`codex-deepseek` for DeepSeek through Codex.

`dot.yaml.disabled` retains the former installation and link definitions for
reference; Rotz no longer installs or links this module. Shared OpenViking and
skills modules no longer install OpenCode plugins or create OpenCode links.

Existing OpenCode binaries, sessions, credentials, configuration, and links are
preserved. Previously installed links may still expose these retained files;
they are no longer maintained as an active harness integration.
