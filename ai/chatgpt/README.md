# ChatGPT Desktop personalization

The local agent setup uses `~/.codex/AGENTS.md`, linked to
`ai/agent-instructions/AGENTS.md`. Keep that file as the shared source.
`instructions.md` is optional text for a separate account personalization field.
Keep project-specific information in the corresponding project or repository.

Local file edits do not update account settings or uploaded skills. Verify saved
settings in the relevant app before claiming installation. Personalization text
does not select a model or grant tool access.

Sources:

- [Personalize ChatGPT](https://learn.chatgpt.com/docs/personalize)
- [Desktop settings](https://learn.chatgpt.com/docs/app/settings)
- [Astra prompting](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra)
