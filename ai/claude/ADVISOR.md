# Opus with a Fable advisor

The Linux/macOS settings select `opus[1m]`, advisor `fable`, and `xhigh` effort.
Windows settings leave model selection to the account. The Plain English output
style supplies the concise response and selective advisor guidance.

Use the advisor for unresolved consequential tradeoffs or recurring failures.
Supply a bounded question, evidence, and constraints. Advice does not authorize
actions. Preserve billing consent; a saved setting does not establish actual use.

Use `/advisor` to inspect the selection and `/usage` to inspect usage.
